This project presents an interactive KFC Sales & Performance Dashboard built using Microsoft Power BI. The dashboard transforms raw sales data into meaningful business insights through interactive visualizations, KPIs, and DAX measures.

The main objective is to analyze sales performance, identify trends, and understand product, branch, and customer-level performance.

🎯 Objectives
Analyze overall sales and revenue performance
Identify top-selling products and categories
Compare branch and location performance
Analyze order trends over time
Understand customer purchasing behavior
Identify peak sales periods
Provide actionable business insights through interactive dashboards
